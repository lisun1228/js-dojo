## 0.1 先说结论：323 题的真实结构

323 题按内容分三层：

```
标称 323 题
├── 1 ~ 100：有编号的 100 题
│   ├── 33 题有实际答案（但普遍 1~3 行）
│   ├── 43 题写着「同 X 文档第 N 题」
│   └── 24 题是「同第 X 题」的自我重复
└── 101 ~ 323：223 题被折叠成一整段话

「101-323. 其他题目」→ 原文：「剩余题目（Promise 输出题、深浅拷贝题、原型链题、
                              异步输出题等）都是上面知识点的综合应用」
                              「【Promise 第X题】需要看具体代码才能答输出」
```

**223 道（69%）没有任何内容。**

### 0.1.1 被折叠的 223 题是什么

原文给了一段「核心思路」：

```
- 先判断同步/异步
- 同步按作用域链找变量
- 异步分微任务/宏任务排队
- 对象比较看引用，基本类型看值
- this 看调用方式
```

这段是「输出题」的解题套路：给一段代码，问打印什么。这类题占比高，但**题单里一道具体代码都没有**。

04、05 册补了 15 道经典输出题（10 道事件循环、5 道 Promise/async），带答案与逐行解析。

## 0.5 JS 面试的答题方法论

### 0.5.1 三段式：语义 → 实现 → 边界

JS 题的追问大多落在**实现细节**和**边界情况**上。

以「闭包」为例：

| 段 | 内容 | 时长 |
|---|---|---|
| **① 语义** | 函数 + 它定义时的词法环境，内层能访问外层变量 | 15 秒 |
| **② 实现** | 函数对象上有 `[[Environment]]` 内部槽指向外层环境；V8 里是 `Context` 对象 + 变量被「上下文化」（contextified） | 30 秒 |
| **③ 边界** | 循环里 `var` 导致全部输出同一个值（因为共享同一个环境）；`let` 每轮新建环境解决 | 40 秒 |

### 0.5.2 一个万能补充句式

```
「这个在规范里的定义是 ______，但实际引擎（V8）的实现是 ______。」
```

例子：

| 题目 | 补充句式 |
|---|---|
| 事件循环 | 「规范只定义了 Job Queue，浏览器实现里分成 task queue 和 microtask queue，而且**每个 task 后都会清空 microtask**」 |
| Promise | 「规范里 Promise 是状态机 + 内部槽（`[[PromiseState]]`/`[[PromiseResult]]`/`[[PromiseFulfillReactions]]` 等），V8 里用 `JSPromise` 这个 C++ 对象实现」 |
| Map | 「规范用 `SameValueZero` 比较键，所以 `NaN` 能作为 Map 的键（而 `indexOf` 找不到 `NaN`）」 |
| typeof | 「`typeof null === 'object'` 是 1995 年第一个实现的 bug：用低位标签表示类型，`null` 是空指针（全 0），标签位正好是 `000`（object）」 |

### 0.5.3 四个扣分点

| 扣分点 | 错误说法 | 正确说法 |
|---|---|---|
| **把「宏任务/微任务」当成规范术语** | 「HTML 规范定义了 macroTask」 | 规范里叫 **task** 和 **microtask**（Job）；「宏任务」是社区造的词 |
| **以为 `await` 后面的代码是宏任务** | 「`await` 后面进宏任务队列」 | 是**微任务**（准确说是 `await` 产生一次额外的微任务跳转） |
| **以为闭包一定导致内存泄漏** | 「闭包会泄漏内存」 | 只有「被长期持有且不再需要」才泄漏；正常闭包会被 GC |
| **以为 `Proxy` 能拦截一切** | 「Proxy 能监听所有操作」 | 有 13 个 trap，但 `===`、`typeof` 没有对应 trap；`instanceof` 只能靠 `getPrototypeOf`/`Symbol.hasInstance` 间接影响 |

### 0.5.4 面试官在听什么

| 层次 | 表现 | 评价 |
|---|---|---|
| L1 | 能说出定义（「闭包是函数 + 环境」） | 及格 |
| L2 | 能写出代码（防抖、深拷贝） | 大多数人的水平 |
| L3 | 能说出**底层机制**（`[[Environment]]`、`JSPromise`、三色标记） | 优秀 |
| L4 | 能说出**边界与反例**（`[] == ![]`、`typeof null`、动态高度虚拟列表） | 很优秀 |
| L5 | 能说出**规范与引擎实现的差异**（task vs microtask、async 不用 Generator 了） | 顶尖 |
