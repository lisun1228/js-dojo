## 五、三条答题通用套路

1. **先给结论，再给机制，最后给实践**：BFC 是独立的块级渲染区域 → 触发条件（overflow、float、position、display、flex/grid 子项等）→ 用于清浮动、防 margin 合并、与浮动元素共存的两栏。
2. **主动补边界**：`flex: 1` 展开为 `1 1 0%`，`flex: auto` 展开为 `1 1 auto`，两者差别在 flex-basis 取 0 还是内容宽度。
3. **把题往项目上引**：布局题答完方案，补一句项目里实际采用的方案与原因。
