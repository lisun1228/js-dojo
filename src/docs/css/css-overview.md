## 四、按"被问概率"排的复习优先级

**第一梯队（几乎必问，必须能 90 秒讲完并且有追问储备）**
Q16 居中 → Q11 BFC → Q14 flex:1 → Q7 优先级 → Q9 层叠/z-index → Q1 盒模型 → Q15 三栏布局

**第二梯队（中高级岗高频，区分度所在）**
Q12 position 五值 → Q13 absolute 基准 → Q10 浮动与清除 → Q3 inline-block 空隙 → Q5 隐藏元素对比 → Q24 1px → Q23 单位体系 → Q19 宽高比 → Q20 文本截断

**第三梯队（加分项，答得好很显功底）**
Q26 iOS fixed → Q29 渲染属性 → Q27 CSS3 动画 → Q28 CSS/JS 动画 → Q25 750 设计稿 → Q8 伪类伪元素 → Q4 继承（line-height 陷阱）→ Q31 预处理器 → Q30 link/@import

**基本不考但要知道的**
Q6 选择器分类清单（背 5 类即可）、Q17 margin:auto 原理（属于 Q16 的深挖）、Q18 三角形（口述 border 原理）、Q21 object-fit（30 秒能对比 background-size 就够）

## 五、三条答题通用套路

1. **先给结论，再给机制，最后给实践**。例："BFC 是独立的块级渲染区域——它成立的条件有 5 类——我在项目里主要用它做两件事：清浮动和防 margin 合并。"
2. **主动抛出边界和坑**。考官问 flex:1，你补一句"它和 flex:1 0 auto 的差别在于是否参考内容宽度"，印象分立刻不一样。
3. **把题往项目上引**。任何布局题说完方案，补一句"我们项目里用的是 xx，因为 yy"，避免背诵感。
